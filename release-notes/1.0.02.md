## What's new

- Apple Notes copies now turn the task list into real checkboxes you can tap. The copy is still one way: Thread writes the note, and the next copy replaces anything typed in Notes
- No recording files are sent. The note is created or updated when you stop a session, or save a summary or tasks
- Checkboxes need Full Disk Access for Thread, under System Settings › Privacy & Security › Full Disk Access. macOS does not prompt. Without it, the note still copies and the tasks stay as plain lines
- Thread quits Notes after copying so those checkboxes stay saved. Open Notes again to see the circles
