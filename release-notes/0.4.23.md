## What's new

- The **Notch** is slimmer and now adapts: a narrow idle band widens while you record, so the running timer always has room
- When idle, the notch's right button is a **notepad** that brings the main Thread window to the front (or reopens it if you'd closed it); the meeting chat now appears only while you're recording, next to the notepad
- **Recording keeps running when you close the main window** — it continues behind the notch and reconnects intact when you reopen the window, instead of stopping. Quitting Thread still ends recording
